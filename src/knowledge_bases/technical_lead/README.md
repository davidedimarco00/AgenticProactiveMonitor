# Technical Lead Knowledge Base

Qdrant collection: `kb-technical-lead`

Primary role: `technical_lead`

This collection is reserved for general cross-domain technical knowledge: system architecture, distributed dependencies, observability boundaries, impact analysis and technical coordination concepts.

The Technical Lead also has access to the shared `monitored-system` collection. Deeper specialist knowledge should normally be obtained through collaboration with the corresponding specialist agent rather than by making the Technical Lead a duplicate of every professional role.

This collection must not contain incident ground truth or rules that directly map observations to thesis evaluation answers.
