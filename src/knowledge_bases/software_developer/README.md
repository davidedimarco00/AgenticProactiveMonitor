# Software Developer Knowledge Base

Qdrant collection: `kb-software-developer`

Primary role: `software_developer`

This collection is reserved for general software knowledge relevant to the monitored technology stack: API contracts, validation, exception handling, persistence, framework behaviour and application-level error semantics.

It must describe software concepts and expected technology behaviour without containing scenario-specific diagnoses. Documentation of the concrete Notes Platform remains in the shared `monitored-system` collection.
