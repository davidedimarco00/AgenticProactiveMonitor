# System Engineer Linux Knowledge Base

Qdrant collection: `kb-system-engineer-linux`

Primary role: `system_engineer`

This knowledge base contains general Linux operating-system knowledge that helps the System Engineer interpret runtime observations. It is not documentation of the Notes Platform itself and it does not contain diagnoses for the thesis evaluation scenarios.

The content focuses on:

- processes and `/proc`;
- CPU accounting and load;
- memory accounting and pressure;
- filesystems and storage;
- network interfaces and sockets;
- cgroup v2 concepts relevant to containers;
- read-only inspection commands and the meaning of their output.

The documents are descriptive. They explain what Linux exposes and what a command reports. The agent must decide which information is relevant to the current incident and must derive hypotheses from live observations.

Official Linux kernel documentation and upstream project documentation are used as the main technical references.
