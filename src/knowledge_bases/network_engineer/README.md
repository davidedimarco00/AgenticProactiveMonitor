# Network Engineer Knowledge Base

Qdrant collection: `kb-network-engineer`

Primary role: `network_engineer`

This collection is reserved for general network-engineering knowledge: TCP/IP, interfaces, routing, ICMP, ports, sockets, latency, packet loss and network observability.

It must describe protocols, measurements and inspection techniques without encoding the answer to thesis evaluation incidents. Documentation of the concrete Notes Platform remains in the shared `monitored-system` collection.
