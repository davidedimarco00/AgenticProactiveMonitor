# Application Engineer Knowledge Base

Qdrant collection: `kb-application-engineer`

Primary role: `application_engineer`

This collection is reserved for general application-operations knowledge: service health, dependencies, request flows, HTTP behaviour, logs, latency, observability and runtime interaction between application components.

It must explain concepts and operational evidence without providing pre-written incident diagnoses. Documentation of the concrete Notes Platform remains in the shared `monitored-system` collection.
